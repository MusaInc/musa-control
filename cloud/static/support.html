Musa Control support

Control the AI coding agents on your own computers from your iPad or iPhone.

Connecting a computer

  • Linux server or VPS: Add a computer → Linux server, enter its address and SSH user. Needs Node.js 22 and tmux (no root).
  • Mac: turn on System Settings → General → Sharing → Remote Login, install Node.js 22 and tmux (brew install node tmux), then add it as a Mac.
  • Windows: install WSL2 with Ubuntu (wsl --install -d Ubuntu), then link it with a code from inside Ubuntu.
  • Behind a router: Add a computer → "can't reach", then run the one-line command it shows on that computer.

Signing in to Claude Code, Codex or Gemini CLI

Machines & AI → AI subscriptions → Sign in. The provider's own sign-in page opens; paste back the code it shows if asked. Your subscription stays with the provider and Musa Control doesn't sell AI credits.

Common problems

  • "Host key changed": the computer's SSH identity is different from when you added it. If you didn't reinstall it, don't connect.
  • Computer offline: check the companion: musa-companion info on that computer.
  • Agent won't start: make sure tmux is installed and the AI tool is signed in.
